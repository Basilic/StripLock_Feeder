# LumenPnP StripLock Feeder

A compact and robust strip feeder designed specifically for the LumenPnP pick-and-place machine.

The StripLock Feeder mounts directly onto an additional 2020 aluminum extrusion rail, eliminating the need for a dedicated backplate and reducing overall system complexity.

Its unique locking mechanism uses eccentric cam levers to actuate a vertically sliding clamp. Once locked, the component tape is securely held in place, preventing any movement during machine operation. This ensures improved pickup repeatability and minimizes positioning errors caused by tape displacement.

## Features

- Direct mounting on an additional 2020 aluminum extrusion rail
- No backplate required
- Quick loading and unloading of component strips
- Eccentric cam locking mechanism
- Secure tape retention during operation
- Supports components up to 12 mm in height
- Compact and fully 3D-printable design
- Designed specifically for the LumenPnP ecosystem

## Benefits

- Prevents tape movement caused by machine acceleration and vibration
- Improves pickup consistency and repeatability
- Supports taller components than many existing strip feeder designs
- Simplifies installation and maintenance
- Fast, tool-free tape replacement
- Modular system that can be expanded along the 2020 feeder rail

## Requirements

- One additional 2020 aluminum extrusion rail installed on the front of the machine
- Standard M5 T-nuts and mounting hardware

## Operation

1. Open the eccentric locking lever.
2. Insert the component strip into the feeder.
3. Close the lever to engage the sliding clamp.
4. The tape is securely locked and ready for production.

## Applications

- SMT component strips
- Prototype assembly
- Small-batch manufacturing
- LumenPnP production setups
